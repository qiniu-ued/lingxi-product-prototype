# ADR 0002：先检查环境，再执行固定的本地配置动作

日期：2026-10-23。状态：采用。

## 背景与决策

用户已打开本地工作台，向导只需配置 Codex 和灵矽。项目安装、启动与 AirPlay 操作保留在文档。进入向导先发起一次检查，汇总两项集成的状态后才展示后续步骤。Codex 可以检查 CLI、协议握手和认证；灵矽适配器缺失时返回 unavailable，不将无法检测解释成未安装。

浏览器通过回环 HTTP 请求已运行的 Node 服务。只读诊断与用户点击触发的安装、登录分开，不提供通用 shell/RPC 转发。新副作用接口要求允许的 Origin 和严格输入，仅接受动作枚举与 UUID。

安装选稳定通道 `@openai/codex@latest`，记录实际版本；npm 的 save-exact 和锁文件保留本次解析结果。安装到工作台数据旁的独立工具目录，通过版本命令与 App Server 检查后才原子切换指针。失败清理本次暂存，不覆盖用户全局安装或旧版本。不自动更新现有 CLI；自定义路径优先于工作台管理的 CLI，后者优先于 PATH。

登录使用 Codex App Server 的 account/login/start（ChatGPT），只允许 HTTPS 官方授权域名 auth.openai.com / chatgpt.com。用户在官方页授权，服务等待对应 loginId 的 account/login/completed，再复查 account/read。凭据由 Codex 自身管理，工作台不读取凭据文件。

## 生命周期与限制

安装/登录同一时刻最多一项，异步状态供页面轮询；相同 ID 与动作重试不重复执行，冲突返回 409。状态和最近 20 次 ID 仅在服务内存保存，重启按实际环境重新检测。支持取消、超时和服务关闭清理；npm 安装在独立进程组中运行，取消清理其后代。取消不意味着撤销已完成的安装或授权。

不展示虚构的下载百分比。操作失败仅返回分类错误，不传原始命令输出、邮箱或密钥。安装需要本机 npm 与网络，尚未提供 CLI 自动更新/卸载界面，保留的旧工具目录也不自动清理。灵矽仍使用官方控制台与 Mac 客户端准备步骤；该向导不开放真实 Agent 任务或语音控制。
