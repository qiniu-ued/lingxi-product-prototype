# ADR 0011：常驻设置与可核对的语音交接

状态：采用，2026-10-24。

## 问题

启动检查通过时不会展示向导，已绑定用户难以找到语音执行许可。用户报告语音回答“做不到”，Codex 没有新增任务；执行开关未开启或不确定，尚无云端工具调用记录，不能将拒绝归因于 Codex。唤醒、收音、聊天与授权执行是不同能力，界面需要说明其边界。

## 决定

- 操作台右上角常驻「设置」，路由 `/settings`，支持 `#codex`、`#lingxi`、`#wake`。与 `/setup` 共用实际表单和只读检查，按三个分类配置，不重复实现接口。检查通过不关闭显式打开的设置或向导；启动仍按 ADR 0010 决定是否进入向导。
- 内部切换保留已挂载工作台与各对话内存草稿，隐藏工作台期间卸载音频组件，停止其录音、唤醒与播放；不停止 Codex，不自动恢复麦克风。刷新、退出与直接加载路由仍不持久化草稿。大屏不展示设置入口。
- 唤醒模型下载、麦克风权限与本次关键词编辑集中在设置/向导。底栏保留开始/停止语音操作及设置快捷入口。固定 `wake-keyword` 动作只修改本次服务内存，检测运行时拒绝，不能连接服务、下载文件或启动推理/录音。
- 公开 VoiceState 增加有默认值的工具发现和交接元数据，涵盖仅草稿、等待工具、已提交、已处理控制、被阻止、未交接。`tools/list` 请求只说明列表被读取；`Workbench.start` 返回真实任务回执才能显示 submitted/taskId。后续失败不能覆盖本次已接受的任务，下一次收音清空状态。转写上下文改变时拒绝旧文本。
- 保留现有显式许可、收音时限、项目/对话校验及任务去重；不把 STT 自动提交。工具错误只映射可公开原因，不回传原始提供方错误。语音模型的 TTS 不是开发结果。
- 使用共用角色说明、MCP 初始化 instructions 和明确的工具描述引导云端调用；设置页链接官方配置并允许复制角色说明。官方「无意图识别」不调用技能，需「统一意图识别」及支持工具调用的模型。提示文本不会自动修改云端，也不保证云端遵循；真实设备验证单独记录。

## 兼容与验证

不更改持久 VoiceConfig、数据库或严格 Task/v2 格式；新诊断为进程内状态，旧输入缺字段采用默认值，回退无需数据迁移。新命令仍经严格 schema 与本地 Origin/桌面能力验证。角色说明不含凭证。

服务端真实 WebSocket 替身验证未授权/未交接不执行、真实回执、失败原因、下一收音重置和关键词不启动音频。浏览器验证常驻入口、健康检查后停留、草稿与附件保留、设置项保存和双端交接状态；真实 Electron 验证设置切换、私有进程回收、原生预览与窗口布局。云端智能体、M1 麦克风和实际语音修改仍需用户本机验收。
