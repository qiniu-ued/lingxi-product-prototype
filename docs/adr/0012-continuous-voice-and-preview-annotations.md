# ADR 0012：持续语音会话、批注入口与默认大屏

状态：采用，2026-10-24。

单句端点检测和关闭会话需分离。原实现有约 1.2 秒静音、8 秒无声及 60 秒分段限制；这些不应使已主动开启的对话必须再次开麦。

显式开始或唤醒后保持 conversationActive，在本机等待讲话、上传本句话、等待回复、播报后继续本机等待。待说话 PCM 不上传，短语音前缀仅在授权开麦后保留于有界内存；检测到讲话后由操作台重新暂存当前上下文，再发 listen 创建新的 captureId 并上传前缀。最多缓冲 100 帧，操作台无法及时开始时明确失败并关闭，避免积压。每句话仍受上下文、时限、任务许可与一次提交约束，STT 本身不执行。

单句静音/时长边界只结束分段；回复超时返回本机等待并显示错误，不自动执行旧文本。四秒无音频帧意味着实际媒体流丢失，持续零值帧不是故障。网络断开、设置切换、休眠、退出或显式关闭停止麦克风，重连不自动恢复。云端主动断连必须如实显示，不能保证提供方长连接策略，也不伪造在线状态。

固定设备工具 workbench_voice_close 仅响应主动收音窗口内、同一项目/对话的明确关闭要求。关闭不需要任务执行许可，不会改变权限或中断 Codex。手动关闭始终可用，并取消尚在等待授权的收音操作。云端能否调用关闭工具仍需真实智能体验证。

电脑预览旁常驻「批注修改」，在唯一作品页面点选/高亮后填写元素批注。批注属于项目/对话草稿；可直接带元素上下文提交，也可将带批注标记加入附件。清除、取消、版本失效均保留明确入口和错误，不把视觉标记当作模型已收到要求。

启动默认打开大屏独立窗口，包括无项目空状态；只使用现有显示器，不自动连接 AirPlay、屏幕录制或共享到外部设备。应用可见品牌统一「丽塔同学」，技术标识、数据目录和官方 URL 不变。

公开语音字段有默认值，不更改持久 VoiceConfig、Task/v2 或数据库。验证包含长静音本地帧、分句与新上下文、语音关闭/断开/媒体丢失、实际 AudioWorklet 生命周期、真实 Electron 批注任务参数、空项目默认大屏与窗口布局；真实提供方/M1/远场仍单独验收。
