# ADR 0013：启动连接、本地唤醒与持久用户选择

状态：采用，2026-10-24。依据用户最新要求，取代 ADR 0009/0011/0012 中每次手动开启及重启不恢复本地唤醒的默认策略。语音任务执行许可仍独立且默认关闭。

## 启动与连接

新安装默认自动连接已有绑定的语音服务，同时在操作台自动监听本地唤醒词“丽塔同学”。两者独立：WSS 连接不等于上传音频，待唤醒帧只进入本地 Worker。唤醒需要可用模型与已经 granted 的麦克风权限，自动路径只读权限状态，不弹授权、不下载模型、不创建设备或凭证。缺项显示设置入口；启动诊断本身仍只读。

Node 服务启动后检查已有加密配置并连接，不依赖浏览器点击。空闲时每 20 秒发送 WebSocket ping，超过 45 秒未收到 pong 视为连接故障。可恢复故障按 1/2/4/8/16/30 秒退避，连续最多六次；之后显示暂停重连，允许用户重试。稳定连接 30 秒后重置连续失败预算。认证失败、格式不兼容不自动重试；网络 online 提示（至少间隔五秒）及系统恢复可重新评估，但不能覆盖用户关闭选择。退出清理所有计时器、连接和音频资源。

唤醒时必须已有绑定、当前项目以及 ready 的服务连接，才能重新暂存本轮上下文并进入交互；连接未就绪时提示真实状态并继续本地等待，不能借唤醒绕过重连退避或手动断开。重连不重放任务，也不恢复旧的云端收音。

## 用户意图与迁移

用户数据目录增加两个非秘密的版本文件：`wake-preferences.v1.json` 和 `voice-connection-preferences.v1.json`，各自仅含 version、enabled 与 source。它们独立于令牌、VoiceConfig、Task/v2 及数据库格式。

首次创建数据库前判断是否已有安装：新安装持久记录 default/on；已有数据库却无相应偏好文件，旧版无法区分原默认值与主动关闭，采用 legacy-review/off，分别在设置中确认一次。显式选择记录 user。损坏或不可写时采用 unavailable/off 并显示问题，不猜测许可；旧版可忽略这些文件。

- 「关闭语音」或云端明确调用语音关闭：立即停止输入和唤醒，将唤醒、自动连接都保存为关闭，并断开服务。即使保存失败，也必须释放资源并显示错误。
- 「关闭语音唤醒」：保存唤醒关闭，释放本地输入，保留服务连接。
- 「断开语音服务」：保存自动连接关闭，取消重试；可以继续本地待唤醒，但唤醒不能重新连接。
- 正常进入设置临时释放音频，不改长期选择；返回按偏好、模型与现有授权判断是否恢复本地唤醒。
- 撤权、真实音频丢失和休眠暂停当前检测，不密集重试；完整重启可依未被关闭的偏好恢复。显式关闭不能因 focus、刷新、断线重连而被覆盖。

## 音频与验证

应用请求系统默认音频输入，可能是物理麦克风或用户选择的虚拟回环。请求处理参数与实际 `getSettings()` 分开显示。应用 TTS 及结束后 600ms 抑制帧，之后恢复；不承诺过滤其他播放器。完整审计和 Mac 对照步骤见 [音频来源说明](../audio-input-and-echo.md)。

验证覆盖偏好初始/迁移/错误/重启、启动连接且无音频上行、静音保活、断线退避及耗尽、认证失败、并发启动、主动关闭、未授权/缺模型不开麦、唤醒进入会话、撤权与设置返回，以及 TTS/尾音后的输入恢复。Electron 检查真实文件及跨进程关闭；浏览器授权与音频使用受控替身，M1 麦克风、远场、真实七牛链路和 AirPlay 仍需单独验收。
