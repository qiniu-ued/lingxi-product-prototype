# ADR 0013：操作台预览滚动

- 日期：2026-10-25
- 状态：已实现

操作台展示唯一作品页面的实时截图，原先滚轮不会传到作品，长页面无法在操作台向下浏览。

新增固定私有 `desktop.scroll` 动作，仅可信操作台主框架可调用。严格校验当前完整预览绑定、归一化指针坐标和有界横纵滚动量，再按预览操作队列发送原生滚轮事件。原生事件保留页面内部滚动容器与滚动链行为；操作不启动 Codex，不发布新版本，也不刷新页面。无重试与持久回执，过期绑定拒绝，滚轮手势不重放到新页面。

大屏仍拥有唯一 WebContentsView；操作台下次截图反映同一滚动位置。批注模式允许先滚动后点选，点选仍不触发作品按钮。生成页面仍无 preload、Node、IPC 或本机服务权限；不开放任意输入事件、脚本或通用 RPC。静态和实时预览、数据库格式均不变。

真实 Electron 集成覆盖操作台滚轮使唯一页面滚动、内部容器滚动、过期/越界输入拒绝、被动大屏不能调用，以及滚动不触发投票或重新发布。
