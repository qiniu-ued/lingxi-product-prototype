# ADR 0014：默认语音配置与常开诊断

状态：采用，2026-10-24。根据用户明确要求，取代 ADR 0013 中旧安装需确认一次及语音执行默认关闭的策略，并取代详细日志的可选启用策略。

## 默认值与迁移

自动连接服务、语音执行和自动本地唤醒在新安装、旧配置缺字段时均默认 true。连接与唤醒继续各自保存 version/enabled/source；无文件、缺 enabled 或可识别的 legacy-review 旧默认迁移为 default/on 并原子保存，不再通过已有数据库猜测用户选择。已有 false 保留，缺 source 的 false 也保守保留。损坏、不可写或 unavailable 状态仍关闭并提示处理。

设备配置的 allowVoiceSubmit 缺字段时按 true 读取；读取不重写加密凭据，正常保存写出具体值。已存 false 无法区分旧默认与主动选择，因此保留；重新绑定也保留已有设置，新绑定才采用默认 true。前端初值与共享协议一致，高级表单同步已保存选择。语音执行保存后需重新连接。

默认开启不绕过设备绑定、模型和系统麦克风授权，不提高 Codex 执行权限，不把唤醒待机音频上传。用户关闭仍持久生效；断线不恢复旧收音、重放任务或覆盖关闭选择。连接的保活、有限退避和错误显示继续遵循 ADR 0013。

## 常开诊断

摘要和详细调试从服务启动就持续记录，不提供启停 UI/API，不读取旧的日志关闭选择。清空只删除缓存，后续继续记录；服务退出清空并停止，重启重新记录。摘要维持 128 条/30 分钟；详细日志维持 64 条/10 分钟、每条 payload 最多 8192 字符及结构/字符串边界，标明截断和轮转，并非完整无限抓包。

详细日志包含转写、助手文字、工具参数/返回、响应字段及连接事件；凭据与绑定身份在截断前脱敏。它是经过修改的详细 payload，不含二进制音频、整个配置或环境变量，不落盘、不增加远端上传。界面明确含对话与项目内容，保留预览、独立复制与失败手动复制；摘要复制不得夹带正文。常开日志不申请麦克风或新增绑定权限。

这些变更提升默认可用性与排障证据，不构成断连根因的确认或修复。真实 Mac/七牛持续连接仍需日志复现验收。
