# ADR 0016：常驻会话导航与公开执行过程

状态：采用，2026-10-25。调整 ADR 0008/设计师暖色桌面的导航入口，不改变对话、任务或项目文件的数据格式。

## 已复现问题

Fork 按钮调用官方 thread/fork 并立即选择子会话；该操作不执行新模型任务，也没有确认/取消弹窗。父会话和 parentId 已持久保存，但会话下拉框藏在默认折叠的「工作区」，主界面没有返回入口。新 Fork 的工作台历史为空，用户无法通过选中回复使用「引用到原对话」。旧 UI 的隔离浏览器回归确认创建成功后「切换对话」不可见，而非原会话被删除。

另外，公开助手 delta 已展示，但 item 完成快照会把已有消息移到末尾；交错完成可能改变顺序。item/commandExecution/outputDelta 未处理，因此命令运行期间的输出可能缺失。

## 决定

操作台对话区常驻会话列表、当前选择、搜索和新建入口。Fork/Sidechat 提供「返回原对话」，使用已有 parentId 和 select-thread；返回不删除分支，不回滚共享文件。重命名/归档仍在「工作区」。搜索不能把当前选择隐藏，切换时重置搜索；仅列当前项目，当前项或直接父项即使已归档仍可定位。父项缺失时明确提示，不发送猜测的目标。

切换沿用既有串行执行约束：任务或导航正在进行时禁用并说明，后端继续拒绝运行中的切换，不偷偷中断、重新提交或把流转到其他会话。Fork 在请求中禁用，避免连续点击重复创建。失败保留原选择和草稿。没有项目/没有会话/连接中断分别显示状态；大屏不提供会话编辑或切换控件。

选中会话、父子关系和已接受任务历史保存在原数据库，刷新/重启恢复。项目切换继续使用原有选择规则，返回项目后仍能从列表定位所有该项目的会话；不新增每项目的导航栈。草稿仍为当前页面内按项目/会话隔离，切来切去保留，刷新/重启不保留。会话切换不是浏览器页面导航，不写浏览器历史；浏览器前进/后退用于工作台与设置等页面，回到工作台仍显示服务保存的选择。

公开助手消息和执行项按首次观察顺序原位更新；完成快照替换同 id 内容，不移到末尾或重复追加。命令输出分片追加到对应 commandExecution 的 text，保持每项 64k 字符上限；完成时采用服务给出的 aggregatedOutput，避免再追加一遍。只处理当前实际 thread/turn 的事件；内部 reasoning 项不进入公开消息/执行记录。无需改变严格 Task/v2 schema，也不请求或展示隐藏推理。

中途助手文本和最终回复在操作台与大屏逐条展示。命令等执行项保持电脑侧「本轮详情（⋯）→ 执行记录」的现有折叠入口；实时状态仍在实际 Codex 进度区，不为本次修复重做终端或完整事件查看器。只声明已覆盖的公开 agentMessage、commandExecution、计划/差异及既有 item 生命周期，不承诺每种未来 API 通知都显示。

## 验证

隔离浏览器覆盖 Fork/Sidechat 返回、双向草稿保留、重复分支/请求中重复点击、搜索未命中、项目过滤、空列表、运行/失败、设置前进后退。独立 Node/App Server 替身覆盖父子/历史持久化、切项目返回、重启，以及两条中途助手消息、实时命令开始/分片/完成、最终回复、重复完成通知、错线程、内部 reasoning 排除和恢复。

真实 Linux Electron 使用隔离数据库和可控多步 App Server，验证操作台/大屏实际 SSE 渲染顺序、运行中输出、列表和返回、刷新与重启后恢复，以及多尺寸、预览/批注和退出回归。该证据不等同真实 Codex 模型、Mac 或设计师具体操作已验收；不操作用户现有 Mac 会话。运行/部署方式不变，仍需重启桌面应用才能载入已构建的新代码。
