# ADR 0017：公开消息时间线与预览截图恢复

状态：采用。扩展 ADR 0016；不改变 Task/v2 正文格式或唯一作品页面边界。

## 已确认的问题

隔离浏览器复现：先前未提交 Codex 的语音讨论会出现在后续 Codex 任务之后；关联语音又整块置于任务回复之前。单一 Codex 消息数组的顺序正确，不代表跨来源的对话时间线正确。旧记录未保存逐条 Codex 到达时间，不能从已有最终文本推断精确的历史交错。

截图由桌面 `capturePage` 提供。Mac 现场记录持续 `Current display surface not available for capture` / `UnknownVizError`，任务实际已完成；电脑端吞异常并每 1.2 秒重试，永远显示“正在同步…”。隔离浏览器复现抛错及请求不返回时均无错误/恢复入口。相同文本在 Electron 上游有不同版本/平台报告，不能据此认定 Mac 的具体 GPU/窗口根因。

## 消息顺序决定

新增 `workspace_message_times_v1` 旁表，每个任务仅保存公开 prompt/assistant/addition 的 ID、首次本机观察时间及序号，不复制正文。通过派生 HTTP/SSE 字段 `messageTimes` 传递，严格 Task/v2、`workspace_state_v2`、旧回执和语音正文内存生命周期不变；旧二进制忽略独立表，降级不自动删除数据。

新消息只记录一次：空的公开 agentMessage started 可先预留位置；后续分片、重复/完成快照和文本修正沿用该位置。补充输入在请求送出前记录。公开助手数组也保持首次观察顺序，内部 reasoning 不进入时间线。

渲染按已知消息时间合并语音、Codex 和用户补充，不因获得 task ID 而把整段语音挪到任务前。重复的已关联用户转写只显示一次，交接状态与真实任务结果独立。相同时间采用稳定规则；记录的是本机观察时间，不是云端原始发生时间。旧任务无逐条元数据时按已知轮次时间保留原有消息顺序，不回填伪造历史。语音刷新/服务退出的原生命周期不变。

## 截图决定

同一视图/绑定/动作版本的截图使用一个原始进行中请求，调用者等候最多 4 秒；超时后原始请求未返回前仍复用，避免重试积累底层 capture。DOM 读取和 capture 之间及返回前检查视图/绑定/动作版本；忽略旧页面结果并拒绝空图。页面动作的幂等回执仍在执行前预留，截图失败不重放点击、输入或滚动。

电脑侧另有 5 秒看门狗；连续失败最多三次，失败后依次等待 1.2、2.4 秒，之后停止自动轮询。挂起请求不靠周期性 tick 发起更多 native 调用。错误可见并提供手动重试；同一绑定可显示上次成功截图并明确过期，换绑定不能显示旧图，错误时禁用新批注点选。仅显式重试/实际恢复才清除错误，离开或换页使旧回调失效。

不自动切换 GPU、禁用系统安全设置、重开/重载用户作品、连接 AirPlay 或抢焦点。UI 状态、并发/超时防护与底层 Electron 渲染故障分开验收；Mac 的实际 surface 失败若未复现/定位，继续报告为未解决，不能称已根治。

## 验证范围

覆盖独立元数据持久化/去重、空 started 与迟到正文、重启/切会话、旧 JSON 兼容，以及浏览器双端的混合语音/任务/补充时间线。截图覆盖拒绝、挂起、有界重试、手动恢复、版本变化与晚到截图；真实 Electron 集成验证唯一视图、可控 capture 故障、后续页面操作及退出。协议/故障注入不等同 Mac GPU 问题已修复，也不把系统锁屏或原生窗口行为当作已验收。
