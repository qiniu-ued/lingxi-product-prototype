# ADR 0019：操作台预览可点击体验

- 日期：2026-10-25
- 状态：已实现

普通预览原先只有截图与滚动，点击被禁用，导致已经实现的投票按钮无法在操作台使用。

普通模式将图片内容区内的左键点击映射到唯一作品页面，使用固定 `desktop.preview-click` 私有 IPC。输入严格校验完整预览绑定、归一化坐标与 requestId；只接受可信操作台主框架。主进程按预览队列执行固定原生 mouseMove/down/up，不接受任意事件、脚本或 RPC。派发前保留 requestId；重复请求不重复点击，冲突请求拒绝，导航后旧绑定失效。点击回传当前截图供操作台同步，不发布版本、不提交模型任务、不改变项目数据格式或网络权限。

“批注修改”模式只做原有命中检测与选中，绝不转发作品点击。保留截图留白、缩放与尺寸映射；取消或切换后的过期响应不应用。大屏与操作台仍共享一个作品页面和浏览器存储。

真实 Electron 覆盖操作台点击计票、同 requestId 不重复计票、冲突拒绝及批注不触发按钮。实际六人投票页面另用隔离项目与 session 验证六票 3/2/1、50% 占比、胜者、重复投票限制及刷新持久化；不占用用户正式投票名额。这仍是同一台电脑上六位编号轮流投票，不宣称跨设备身份认证或共享后台。
