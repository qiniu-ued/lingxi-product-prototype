# ADR 0021：统一连接向导入口

状态：采用，2026-10-25。替代 ADR 0010/0011 中向导与设置并存的 UI 与入口安排；只读检查、显式配置操作、语音交接及音频生命周期边界不变。

## 决定

- 首次配置、日常管理与故障处理只使用 `/setup` 连接向导。旧设置内容并入向导，保留 Codex、丽塔同学与语音执行、语音唤醒与麦克风三个分类及实际表单，使用同套 Radix 组件与统一排版；分类直接切换，不重复展示上下步操作。旧 `/settings` 地址保留分类 hash 并兼容归一到 `/setup`。
- 桌面启动仍在工作台草稿与任务挂载前执行并行只读检查；缺项或失败时打开对应分类。点击「返回工作台」可在当前页面继续使用，刷新或重启重新检查；执行中不定时跳转。检查通过不自动关闭已打开的向导页，大屏与浏览器基础模式仍豁免启动门控。
- 工作区保留「连接向导」作为工作台唯一配置入口，删除工作台顶栏独立「设置」和向导页右上角「设置」互跳；原生菜单保留「连接向导」并指向 `/setup`，沿用现有 `loadURL` 行为。
- 内部导航继续保留工作台挂载及各对话内存草稿，进入向导时卸载音频所有者、停止收音/唤醒/播放，返回仅按偏好、模型与既有授权恢复本地唤醒，不恢复旧云端收音。原生菜单加载、刷新或退出仍不保证保留内存草稿。

## 边界与验证

保留现有绑定、安装、登录、固定动作、只读诊断与子进程回收，不改变服务 API、配置存储、任务格式、语音许可或音频生命周期。

验证启动缺项的分类定位、当前页返回及刷新重查、健康向导页停留、`/settings` 分类 hash 兼容、重复入口移除与三个分类的统一组件/排版，以及内部导航的草稿与附件保留、任务不中断和音频停止。协议替身、浏览器及 Electron 验证分别记录，真实账号与 Mac 音频验收不因入口合并自动成立。
