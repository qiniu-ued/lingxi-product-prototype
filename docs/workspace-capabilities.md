# 工作区能力与 Codex 桌面对照

本项目使用公开的 Codex App Server 构建自己的操作台，不嵌入或控制官方 Codex 桌面应用。2026-10-24，协议参照 CLI 0.163.0；安装仍跟随 stable latest。

| 能力                | 当前行为                                                                  | 实际限制                                                                        |
| ------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 常驻对话/历史       | 多对话、多轮次持久保存，可切换、搜索标题、重命名、归档                    | 一次执行一个模型轮次，不导入官方桌面已有聊天                                    |
| 终端                | xterm.js + App Server command/exec PTY；输入/缩放/结束，输出选区加入对话  | 用户主动打开；切换项目或退出会结束；非通用远程 shell                            |
| 回答提问            | 多个问题请求、标题、选项、自由文本、秘密输入和过期请求校验                | 语音转写可填入答案；非阻塞 agentMessage.questions 与直接设备 MCP 回答工具待接入 |
| 浏览器标记          | 多个 DOM 元素标记进入附件，提交时校验版本/导航                            | 尚无拖框区域截图、任意 DOM 到源码映射；未注入官方 document.oai.annotation       |
| Diff                | 实际 turn/diff/updated、Git staged/unstaged、行选取与评论                 | 无自动回退、暂存或合并；未跟踪文件只列名称                                      |
| Sidechat            | 从已结束轮次 thread/fork，read-only/never，禁用 MCP；结论带回主对话       | 与主对话串行，共享文件的只读讨论；非官方 attached Sidechat API                  |
| Fork                | 复制到指定已结束轮次的模型上下文，新聊天继续                              | 共享项目文件；独立 Git worktree/脏工作区快照待实现                              |
| Add to conversation | 终端、diff、浏览器标记、执行记录、文字/代码和 Sidechat 摘录               | 先进入草稿附件，明确提交后才给模型；未做原生文件树和任意文件上传                |
| 执行中补充          | turn/steer(expectedTurnId) 或持久队列                                     | 连接中断不自动重放；队列重启标中断                                              |
| 模型/思考强度       | 输入区自动读取完整 model/list，按模型选择兼容强度                         | 取决于账户和 CLI；不硬编码可用模型                                              |
| 上下文统计          | 最近请求占用率、剩余量、输入/缓存/输出/推理及累计用量                     | 来源为最近 Codex 上报，不估算草稿或逐文件 token；未知值不显示假 0%              |
| 计划                | 指令要求先给计划并确认，显示真实计划事件                                  | 官方 collaboration Plan mode 尚未接入                                           |
| Skills/MCP/额度     | 按需独立读取列表和限额                                                    | 目前只读，插件安装、MCP OAuth/配置编辑未实现；可粘贴技能说明/准确指令           |
| 框架项目预览        | 终端启动项目，再明确绑定 loopback HTTP 地址                               | 精确 origin/HMR WebSocket；不放开外部 CDN/API，不托管公网服务                   |
| 灵矽绑定            | OTA 申请六位码、官方网页登录授权、检查绑定、自动获取并加密保存连接配置    | 未以真实账户验收；不下载任何 OTA 固件                                           |
| 灵矽语音            | 手动收音、PCM 16kHz、STT 草稿、TTS 测试/停止、可选设备 MCP 提交/查询/停止 | 需真实服务支持 PCM；已接任务结束/提问通知；未接 Opus、自定义本地唤醒和语义摘要  |
| AirPlay             | macOS 手动连接，显示已有外接屏                                            | 无浏览器 AirPlay API、无假 PIN/假已连接状态                                     |

原型里多 Agent 名称不等于真实 Codex 子 Agent。当前执行记录显示真实 item 类型与内容，尚未提供完整子 Agent 树、代码审阅专用视图或 Codex 官方桌面所有设置。

扩展顺序：先完成 M1 Pro 真实账户/音频/模型闭环；再推进区域截图、独立 worktree、并发 Sidechat、官方 Plan/Skills 调用、审阅及自动摘要播报；最后评估本地唤醒词和 macOS 投屏自动化。每项都应补契约、异常路径和真实设备证据。
